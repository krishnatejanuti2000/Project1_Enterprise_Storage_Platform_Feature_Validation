Module          : Module 2 - RAID Data Protection
Topic           : RAID 0
Lab             : RAID 0 Creation and Validation
Evidence ID     : 02
Evidence Name   : RAID Status Verification Before Cleanup

============================================================
Objective
============================================================

To verify the current RAID configuration, identify active RAID
arrays, and understand the status of all RAID devices before
performing any cleanup or creating a new RAID 0 array.

============================================================
Command Executed
============================================================

$ cat /proc/mdstat

============================================================
Command Output
============================================================

Personalities : [raid0] [raid1] [raid4] [raid5] [raid6] [raid10] [linear]

md127 : active raid0 sdb[0] sde[1]
      585672704 blocks super 1.2 512k chunks

md0 : active raid0 sdc[0] sdd[1]
      425620480 blocks super 1.2 512k chunks

unused devices: <none>

============================================================
Validation Result
============================================================

PASS

============================================================
Observations
============================================================

• The Linux kernel currently supports multiple RAID personalities,
  including RAID 0, RAID 1, RAID 4, RAID 5, RAID 6, RAID 10, and Linear RAID.

• Two active RAID 0 arrays are present in the system.

• RAID array md127 consists of:
  - /dev/sdb
  - /dev/sde

• RAID array md0 consists of:
  - /dev/sdc
  - /dev/sdd

• Both arrays are active and operating normally.

• The metadata version is 1.2.

• The configured chunk size for both arrays is 512 KB.

• There are no unused RAID devices.

============================================================
Conclusion
============================================================

The current RAID configuration has been successfully verified.
Two active RAID 0 arrays exist in the system. Before creating a
new RAID 0 array for validation, the existing RAID configuration
must be stopped and the member disks cleaned.
